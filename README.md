## 增量水位尺

每个读盘任务配一把水位尺（`Watermark`），两种推进法各存一个尺位，当天由「本日推进策略」决定读哪个，尺上读数可点进读盘详情。

- **本日推进策略二选一，写死即锁**：`跟源文件最大变更时刻` 或 `跟本任务上次成功解析条数`，当天只许一种、不许改弦；读盘执行中也不得改策略。
- **推进写歪要拦住**：点读盘带的推进法若与当日策略不符，页面提示「水位尺推进写歪了」并拒绝执行。
- **全量可越尺，但必须填原因**；**增量只收尺位之后的变更**。
- **空编码行不推尺**：照样被收到，但不参与尺位推进。
- **争抢只记先到**：同一读盘任务已有执行中的读盘时，后到读盘直接判「争抢落败」，留争用落败说明，不收行不推尺。

页面：

- 水位列表（`/jobs/`）并排展示两个尺值、今日已析、落档数、推进法名，尺值本身可点。
- 读盘详情（`/jobs/<id>/`）可展开推进轨迹、争用落败说明与源文件行。

领域与规则集中在 `catalog/services.py`，验收用例见 `tests/test_watermark.py`。
